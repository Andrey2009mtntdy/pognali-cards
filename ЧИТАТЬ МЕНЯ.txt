КАРТОЧКИ ДЛЯ МАРКЕТПЛЕЙСОВ · ПОГНАЛИ РФ
=======================================

Программа делает две карточки на модель: главную и комплектацию.
Размер 1024 x 1280, макет всегда одинаковый — меняются только фото и текст.

Главная карточка собрана по образцу каталога: фирменный фон с горами, логотип
сверху, слева колонка — бренд, модель, батарея и три плашки характеристик,
снизу лента «гарантия / маркировка / влагозащита», товар справа.
Акцент по умолчанию оранжевый. Если нужен тёмный вариант — галочка «Тёмный фон».


ФОН
---

Подложка выбирается списком «Фон карточки» и ставится сразу на обе карточки.
В списке — все картинки из папки «фоны» плюс вариант «Рисованный»: там фон
программа рисует сама, картинка не нужна.

Свой фон добавляется прямо из программы:

      Файл -> Добавить фон…             Ctrl+Shift+O

Выбираешь картинку (можно сразу несколько), она копируется в папку «фоны»,
сразу появляется в списке и подставляется в предпросмотр. Перезапускать
программу не нужно.

Файл с таким же именем не затирается — к новому дописывается номер,
«горы (2).png». Посмотреть и почистить папку: Файл -> Открыть папку с фонами.

Можно и вручную: положи PNG или JPG в папку «фоны» рядом с exe — они появятся
в списке при следующем запуске. Пересобирать программу не надо.

      Карточки Погнали РФ.exe
      каталог.txt
      фоны\
         горы.png       (комплектный)
         свой-фон.png   (твой)

Размер лучше 1024 x 1536: программа растянет по ширине, а лишнее снизу
обрежет, поэтому важное держи в верхних двух третях.


ЦВЕТ ПОЛОС НА ФОНЕ

Галочка «Красить полосы фона акцентом» перекрашивает оранжевые мазки подложки
в выбранный цвет. Меняется только тон: фактура кисти, брызги и полупрозрачные
края остаются на месте — это не заливка плашкой.

Трогаются только оранжево-жёлтые цветные пиксели. Серые горы, снег и текстура
бумаги остаются как были: у них нет цвета, программа их не считает мазками.
Если на твоём фоне мазки другого цвета — скажем, синие, — перекраска их не
возьмёт, сними галочку и крась файл в редакторе.

При галочке «Тёмный фон» подложка не используется — там рисованный тёмный фон,
иначе белые горы вылезли бы под светлую типографику.


ЗАПУСК
------

Открой файл:   СБОРКА\Карточки Погнали РФ.exe

Ничего устанавливать не нужно, интернет не нужен. Можно скопировать этот exe
куда угодно — на флешку, на другой компьютер — и он будет работать.

Рядом с exe держи файл «каталог.txt» — тогда список моделей подхватится сам.


КАТАЛОГ МОДЕЛЕЙ
---------------

Слева в окне стоит колонка со списком всех великов — рядом с полями и
предпросмотром, тремя колонками. Выбрал модель, и бренд, версия, батарея,
характеристики, нижняя лента и все восемь блоков комплектации уже заполнены.
Дальше остаётся подставить фотографии и нажать «Сохранить карточки».

Кнопка с тремя палочками (☰) слева сверху сворачивает и разворачивает эту
колонку: свернул — поля и предпросмотр стали шире. То же делает крестик-стрелка
в самой колонке.

Название выбранной модели видно в шапке рядом с логотипом.

То же самое есть в верхнем меню:
   Файл   -> Загрузить каталог моделей…   Ctrl+O
           Добавить фон…                  Ctrl+Shift+O
           Открыть папку с фонами
           Выбрать папку с фото…          Ctrl+D
           Пакет: все папки…              Ctrl+B
           Сохранить карточки             Ctrl+S
   Модели -> Список моделей               Ctrl+M

Откуда берётся список:
   1. Файл, который ты указал через «Файл → Загрузить каталог моделей…» —
      путь запоминается, при следующем запуске подхватится сам.
   2. Файл «каталог.txt» рядом с exe.

Образец лежит в папке «модели\каталог.txt» — скопируй его к exe и правь под себя.

Как устроен файл: модели разделены заголовком в двойных равно, внутри — обычные
строки «что: значение». Пустые строки и строки с # программа пропускает.

      === KUGOO WISH 02 PRO ===

      Бренд: KUGOO
      Модель: WISH
      Версия: 02 PRO
      Батарея: LI-ION | 60В / 27Ач

      Гарантия: 3 месяца
      Маркировка: 240
      Влагозащита: IP54

      Характеристика 1: 2500 Вт | МОЩНОСТЬ
      Характеристика 2: 70 км/ч | СКОРОСТЬ
      Характеристика 3: 150 кг | НАГРУЗКА

      Комплектация:
      1. ЗЕРКАЛА | заднего вида
      2. ДИСПЛЕЙ | информативный
      ...

      === KUGOO WISH 03 ===
      ...

Слева от вертикальной черты — название, справа — пояснение мелким шрифтом.
Пояснение можно не писать, тогда просто оставь черту в конце.

Добавить велик = дописать новый блок в конец файла. Программу пересобирать
не нужно: она читает каталог при каждом запуске.

Если моделей много, над списком есть поиск по названию.


КАК ПОЛЬЗОВАТЬСЯ
----------------

1. Нажми «Выбрать папку с фото» и укажи папку модели.

2. Программа сама разложит фотографии по местам — по именам файлов:

      перед.jpg        -> главное фото
      зад.jpg          -> фото на второй карточке (можно «сбоку.jpg»)
      зеркала.jpg      -> блок «ЗЕРКАЛА»
      дисплей.jpg      -> блок «ДИСПЛЕЙ»
      тормоза.jpg      -> блок «ТОРМОЗА»
      аккумулятор.jpg  -> блок «АККУМУЛЯТОР»
      фара.jpg         -> блок «ФАРА»
      фонарь.jpg       -> блок «ФОНАРЬ»
      подножка.jpg     -> блок «ПОДНОЖКА»
      амортизатор.jpg  -> блок «АМОРТИЗАТОРЫ»

   Понимает ещё: колесо, шина, сиденье, багажник, корзина, руль, мотор,
   поворотники, рама. Регистр и расширение не важны.
   Что не распознает — разложит по оставшимся местам по порядку.

3. Выбери модель через ☰ — поля заполнятся сами.
   Если модели там нет, заполни руками. Что куда идёт на главной карточке:

      Бренд                -> KUGOO, чёрным над названием
      Модель + Версия      -> WISH 02 PRO, крупно оранжевым
      Батарея — тип        -> LI-ION, рядом с оранжевой плиткой
      Батарея — ёмкость    -> 60В / 27Ач
      Характеристики (3)   -> плашки: мощность, скорость, нагрузка
      Гарантия / Маркировка / Влагозащита -> лента внизу карточки

   Комплектация (8 блоков) идёт на вторую карточку.
   Справа сразу видно, как получается.

4. Нажми «Сохранить карточки» и укажи, куда положить.
   Рядом с фото сохранится файл данные.txt — в следующий раз программа
   подставит всё сама.


КАДРИРОВАНИЕ: ДВИГАТЬ, МАСШТАБИРОВАТЬ, ПОВОРАЧИВАТЬ
---------------------------------------------------

Под двумя карточками есть большая область «Кадрирование» — там фото видно
крупно, щуриться в мелкий блок не нужно.

Как работает:
   1. Кликни нужный слот в разделе «Фотографии» (Главная, Блок 1, Блок 2…).
      Фото откроется в области кадрирования.
   2. Жёлтая рамка — то, что попадёт на карточку.
      Всё за рамкой показано приглушённо: видно, что осталось за кадром.
   3. Тяни фото мышью — двигаешь.
      Крути колесо мыши или тяни ползунок «масштаб» — приближаешь.
      Ползунок «поворот» — наклоняешь, от -180° до 180°.
      Карточка справа обновляется сразу.

Кнопки:
   «⟳ 90°»   — повернуть на четверть оборота: для фото, снятых боком.
   «Вписать» — показать фото целиком внутри рамки (если оно обрезается).
               Повёрнутое фото тоже вписывается целиком, углами за рамку
               не вылезает.
   «Сброс»   — вернуть как было: без сдвига, масштаба и поворота.

Настройки кадра сохраняются в данные.txt (строки «Кадр kit3: …»), так что
при следующем открытии папки всё останется как настроил.

Если положить в слот другое фото — подгонка для него сбрасывается,
чтобы новая картинка не встала криво по старым настройкам.


ЕСЛИ НАДО СРАЗУ МНОГО МОДЕЛЕЙ
-----------------------------

Сложи папки моделей в одну общую папку:

      Модели\
         KUGOO WISH 03\   (фото + данные.txt)
         KUGOO WISH 04\   (фото + данные.txt)
         ...

Нажми «Пакет: все папки», укажи эту общую папку, затем куда сохранять.
Программа пройдёт все папки подряд.

Важно: в пакетном режиме данные берутся из данные.txt в каждой папке.
Если файла нет — бренд и модель возьмутся из названия папки.


ФОТО И ФОН
----------

Галочка «Убирать фон у фото» вырезает белый фон у главных фотографий —
на тёмной карточке товар должен стоять без белого прямоугольника.

Ползунок «Сила вырезания фона»:
   больше — чище убирается фон и студийная тень,
            но при переборе может «съесть» тёмные детали товара;
   меньше — товар целее, но может остаться светлый ободок.

Подвинул ползунок — картинка пересчитается, сразу видно результат.
Если фото уже без фона (PNG с прозрачностью) — сними галочку.


ЦВЕТА
-----

По умолчанию стоит оранжевый #F26522 — как на образцах карточек.
Цвет акцента можно поменять в поле «Акцент»: он разойдётся по названию модели,
плитке батареи, иконкам, обводке и подписям нижней ленты, а если включена
галочка «Красить полосы фона акцентом» — то и по мазкам на подложке.

Важно: слишком светлый цвет (чистый жёлтый, лимонный) на белом фоне нечитаем,
поэтому для надписей программа автоматически берёт затемнённый оттенок того же
цвета, а исходный оставляет для заливок и полос.

Палитра:
   #F26522  оранжевый акцент карточек
   #FFDD00  фирменный жёлтый сайта
   #F5A623  золотисто-жёлтый
   #E6B800  приглушённый жёлтый (хорошо читается как текст)
   #FEF3C7  бледно-жёлтая подложка


ЧТО МОЖНО МЕНЯТЬ, А ЧТО НЕТ
---------------------------

Меняется: бренд, модель, версия, батарея, три характеристики, три пункта нижней
ленты, цвет акцента, светлая/тёмная тема, восемь блоков комплектации, фотографии.

Не меняется (заложено в шаблон): размер 1024 x 1280, расположение блоков,
подписи нижней ленты («ГАРАНТИЯ», «МАРКИРОВКА», «ВЛАГОЗАЩИТА») и их иконки,
заголовок «КОМПЛЕКТАЦИЯ И ОСОБЕННОСТИ», логотип.

Цифры программа не придумывает — пишет только то, что ты ввёл.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------

Windows ругается «Неизвестный издатель»
   Это обычное предупреждение для программ без платной цифровой подписи.
   Нажми «Подробнее» -> «Выполнить в любом случае».

Фото встало не в тот блок
   Переименуй файл по смыслу (зеркала.jpg, фара.jpg) или перетащи вручную:
   выбери слот в списке и кликни нужное фото в галерее.

В блоке видно не ту часть фото (обрезалось криво)
   Выбери этот слот и подвинь фото в области «Кадрирование» под карточками.

Вокруг товара светлый ободок
   Подвинь ползунок «Сила вырезания фона» вправо.

У товара пропали куски
   Наоборот, подвинь ползунок влево.

Карточка сохранилась пустой
   Проверь, что выбрана папка с фото и заполнены Бренд и Модель.


ДЛЯ РАЗРАБОТКИ
--------------

   npm start          — запустить без сборки
   npm run build      — пересобрать exe (появится в папке СБОРКА)
   npm run logo -- "путь\к\логотипу.png"  — подготовить логотип (убрать фон)
