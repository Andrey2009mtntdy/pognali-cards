# Карточки для маркетплейсов — Погнали РФ

Программа делает две карточки на модель: главную и комплектацию. Размер 1024 × 1280,
макет всегда одинаковый — меняются только фотографии и текст.

Выбираешь велик из списка слева, указываешь папку с фотографиями, нажимаешь
«Сохранить карточки». Ничего устанавливать не нужно, интернет не нужен.

## Скачать

Все версии — на странице [Releases](https://github.com/Andrey2009mtntdy/pognali-cards/releases/latest).

| Система | Файл |
|---|---|
| Windows | `Pognali-Cards-…-windows.exe` |
| Mac на Apple Silicon (M1–M4) | `Pognali-Cards-…-mac-arm64.dmg` |
| Mac на Intel | `Pognali-Cards-…-mac-x64.dmg` |

Не знаешь, какой у тебя Mac: меню  → «Об этом Mac». Если в строке «Чип» написано
Apple M1/M2/M3/M4 — бери **arm64**, если Intel — **x64**.

## Установка

### Windows

Скачай exe и запусти — он самодостаточный, его можно положить хоть на флешку.

При первом запуске Windows покажет синее окно «Windows защитила ваш компьютер».
Это обычное предупреждение для программ без платной цифровой подписи:
нажми **«Подробнее» → «Выполнить в любом случае»**.

### macOS

Открой dmg и перетащи программу в «Программы».

При первом запуске macOS скажет, что приложение повреждено либо что разработчик
не проверен. Цифровой подписи Apple у программы нет, поэтому система помечает
скачанный файл карантином. Снимается одной командой в Терминале:

```sh
xattr -cr "/Applications/Карточки Погнали РФ.app"
```

После этого программа открывается обычным двойным щелчком.

## С чего начать

1. **Список моделей** — колонка слева. Выбрал велик, и бренд, версия, батарея,
   характеристики и все восемь блоков комплектации заполнились сами.
   Свой список: «Файл → Загрузить каталог моделей…».
2. **Фотографии** — «Файл → Выбрать папку с фото…». Программа сама разложит их
   по местам, если файлы названы по смыслу: `перед.jpg`, `зеркала.jpg`, `фара.jpg`.
3. **Кадрирование** — область под предпросмотром: фото можно двигать,
   масштабировать и поворачивать.
4. **Сохранить карточки** — Ctrl+S.

Подробности — в файле [ЧИТАТЬ МЕНЯ.txt](ЧИТАТЬ%20МЕНЯ.txt): формат каталога,
свои фоны, перекраска фирменного цвета, пакетная обработка папок.

## Разработка

```sh
npm install
npm start          # запустить без сборки
npm run build      # собрать под текущую систему, результат в папке СБОРКА
npm run icon       # пересобрать иконку из логотипа
```

Карточки рисуются на обычном canvas в окне программы — нативных библиотек нет,
поэтому сборка идёт без компиляции под каждую платформу.

Релизы собираются автоматически: пуш тега `v*` запускает
[workflow](.github/workflows/release.yml), который собирает Windows и macOS на
машинах GitHub и выкладывает файлы в Releases.

```sh
npm version patch      # поднять версию в package.json и поставить тег
git push --follow-tags
```
